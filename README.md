# DataPulse AI 📊🤖

An end-to-end full-stack data analytics platform powered by **FastAPI**, **React (Vite)**, and Large Language Model agents. Upload datasets (.csv, .xlsx) and query natural language analytics with dynamic charts and executive summaries.

---

## 🏗️ Architecture

- **Backend**: Python 3.11, FastAPI, Pandas, NumPy, Uvicorn
- **Frontend**: React, Vite, Recharts, Tailwind CSS
- **AI Analytics Engine**: LLM-driven Pandas execution engine
